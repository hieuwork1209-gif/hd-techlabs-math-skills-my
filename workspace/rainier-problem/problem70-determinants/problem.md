# Normalized Math Problem

## LaTeX (Normalized)

Let $S_5$ be the symmetric group on $\{1,2,3,4,5\}$. Index the rows and columns of a $120\times120$ matrix $A$ by the elements of $S_5$. For $\sigma,\tau\in S_5$, define
$$
A_{\sigma,\tau}=
\begin{cases}
5,&\sigma=\tau,\\
-1,&\sigma^{-1}\tau\in\{(12),(23),(34),(45)\},\\
0,&\text{otherwise}.
\end{cases}
$$
Determine $\det A$.

---

## Domain Classification

| Field | Value |
|---|---|
| **Domain** | Linear Algebra |
| **Sub-domain** | Determinants |
| **Problem Type** | Exact computation |
| **Answer Type** | Exact scalar |

---

## Domain Explanation

The matrix is $I+L$, where $L$ is the graph Laplacian of the Cayley graph of $S_5$ generated by the adjacent transpositions $(12),(23),(34),(45)$, i.e. the type-$A_4$ permutahedron graph. Determining its exact determinant requires the spectrum of a concrete noncentral convolution operator, so Linear Algebra -> Determinants is the primary classification.
